# Estudio de contenido Hestía · kit para el Proyecto de Claude

Sistema reutilizable para generar posts de Instagram y Facebook cada semana,
con la voz de marca y sin inventar datos.

## Montaje (una vez)
1. En claude.ai, crea un Proyecto llamado **"Estudio de contenido Hestía"**.
2. En las instrucciones del Proyecto, pega el contenido de **`system-prompt.md`**.
3. Sube al Proyecto estos archivos de referencia:
   - `hechos-y-ventajas.md` (la fuente de verdad, anti-invención)
   - `temporadas-y-eventos.md` (ganchos de calendario)
   - `ejemplos-captions.md` (referencia de estilo)
   - `VOZ-DE-MARCA.md` (del repo, la voz)
4. (Opcional) Conecta **Google Drive** a la carpeta con las fotos de los
   apartamentos: así el Proyecto sugiere qué foto concreta usar en cada post.

## Uso (cada semana)
Abre el Proyecto y pídele lo que necesites, por ejemplo:
- "Dame 3 posts para esta semana: uno de Salinas con las salinas al amanecer,
  uno de mascotas bienvenidas y uno para el hueco del 12-15 en Mar."
- "Propón 3 ideas de post para agosto y escribe la que más te guste."

Cada post sale listo para pegar en vuestro panel de Redes o en IG/FB.

## Control de calidad (10 segundos)
Antes de publicar, mira tres cosas: ¿algún dato que no puedas confirmar?,
¿suena a vosotros o a robot?, ¿enlace y apartamento correctos? Si las tres van
bien, publica.

## Mantenimiento
- Cuando cambie un dato (precio, servicio), actualiza `hechos-y-ventajas.md` y
  vuélvelo a subir. Es el único sitio que hay que tocar.
- Añade tus mejores captions a `ejemplos-captions.md` para afinar el estilo.
